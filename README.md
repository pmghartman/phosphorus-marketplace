# Phosphorus plugin

The Claude plugin for this mesh, written by phosphorus on each release; edits here are replaced.

- Claude Code: `/plugin marketplace add https://git.philab.io/internal/phosphorus-plugin.git`, then `/plugin install phosphorus@phosphorus`, and turn on auto-update for the marketplace under `/plugin`, Marketplaces.
- claude.ai, Claude Desktop or Cowork: Customize, Plugins, Add marketplace: `https://git.philab.io/internal/phosphorus-plugin.git`.

The connector signs in with your mesh user and password. What it may do follows your role.
